# Flavour pictures (SCREAM-129)

- `draw_icons.py`: draws `public/assets/flavours/icons.png`, one 28 x 36 pixel picture per flavour in the order of `FLAVOURS` (eclair, SpongePop, Lil Explorer Pop, cookie sandwich). `python3 tools/flavours/draw_icons.py public/assets/flavours/icons.png`. Placeholders until SCREAM-113's art (SCREAM-130: the Lil Explorer Pop as a face-shaped character pop). Original designs only: no real products or characters.
- The marker font for Today's Menu prices is `public/assets/fonts/permanent-marker.woff2` (Permanent Marker, Apache 2.0, licence next to it).
