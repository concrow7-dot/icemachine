# Project documentation

The paper trail behind Ice Machine. What's in this folder is versioned with the code; the rest lives in the product owner's Google Drive (private) and is listed here so you know it exists.

## In this repo

| Document | What it is |
| --- | --- |
| [Decision log](decision-log.md) | Every product and technical decision, newest first: what was decided, the options considered, the product owner's reason, and engineering's own calls (labelled as proposals). The canonical record. |
| [Browser tests](../tests/e2e/README.md) | How the Playwright suites work and how to run them. |
| [LimeZu art](../public/assets/limezu/README.md) · [Audio](../public/assets/audio/README.md) | What's used from each pack and under what licence. |

## In Google Drive

| Folder | What it holds |
| --- | --- |
| Product Management Decisions | Numbered documents (no gaps): the process deck, development process and roadmap; the residents sheets that name every person in the neighbourhood; the on-screen text style rules; playtest feedback forms and results; and a design doc for each larger feature (the cooler redesign, home restocking, customers walking to the truck). |
| Testing | One test plan sheet per pull request, numbered. The product owner runs each by hand before merging. |
| Devlog | One entry per milestone, in the product owner's voice: what shipped, what was decided and why, what testing found. |
| Personal Notes | The product owner's handwritten notes and sketches, typed up, with the originals. |

## Where things are tracked

- **Work:** Jira, project SCREAM (stories, tasks, subtasks, under epics).
- **Code review and merging:** GitHub pull requests on this repo.
- **Decisions and reasons:** the decision log, above.

The GitHub Issues on this repo are from the first week (October 27 to November 1) and were left as a snapshot when work moved to Jira. Don't use them.
