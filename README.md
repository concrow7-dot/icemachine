# Ice Machine

An ice cream truck video game: a 2D browser game, built in the open as a product management case study.

**Play:** https://concrow7-dot.github.io/icemachine/ (live once the first deploy runs)

## How this project works

- **Product decisions, specs and priorities** live in [`/docs`](docs/).
- **Work is tracked** as GitHub Issues on the project board.
- **Every change** arrives as a pull request, is reviewed and tested, then merged.
- **Every merge to `main`** automatically builds and publishes the game.

## Run it locally

Requires Node.js 22 (LTS).

```
npm install
npm run dev
```

Then open the address it prints (usually http://localhost:5173).

## Tech

[Phaser 3](https://phaser.io) game engine · [Vite](https://vite.dev) build tool · GitHub Pages hosting.
